# Ophel Academy Feeding Fees Tracker (Demo)

A live demo of a feeding-fees tracker I built for a school. It uses made-up students, so anyone can try it safely.

**Try it:** https://delasi9.github.io/ophel-demo/

## What it does
- **Teachers** record Day, Week or Term payments for their own class.
- **The administrator** sees live totals across all classes, filters by class, payment type and date range, prints a report, and downloads the records as Excel or CSV.
- Fee rates (per day, days per week, weeks per term) are editable in Settings.
- Data syncs live between devices.

## Built with
HTML, CSS and JavaScript in a single file, Firebase Cloud Firestore for the live database, SheetJS for Excel export, and GitHub Pages for hosting.

## About this demo
- All students and amounts are invented.
- Use **Reset demo data** at the top of the page to restore the sample records.
- The real school version is private and uses logins.
